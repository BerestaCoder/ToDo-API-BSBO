# ToDo лист API

### Описание
Проект позволяет эффективно управлять задачами с помощью матрицы Эйзенхауэра, помогая пользователям расставлять приоритеты и планировать свою деятельность наиболее продуктивно.

Проект даёт возможность пользователям создавать персональные задания, закрепленные за собственным аккаунтом. Один сервис могут одновременно использовать разные пользователи, каждый из которых имеет доступ только к созданию, изменению и удалению собственных задач. Чтобы наделить аккаунт административными правами, необходимо обновить роль указанного пользователя в вашей базе данных на значение ADMIN.
### Технологии
- Python 3.14
- FastAPI 0.119
- PostgreSQL
### Установка и запуск проекта
Для запуска приложения в режиме разработчика следуйте инструкциям ниже:
##### Шаг 1: Создаем виртуальное окружение
```
python -m venv venv
```
##### Шаг 2: Активируем виртуальное окружение
```
source venv/Scripts/activate
```
##### Шаг 3: Устанавливаем необходимые пакеты
```
pip install -r requirements.txt
```
##### Шаг 4: Запуск сервера:
```
uvicorn main:app --reload 
```
Теперь проект готов к работе!
### Конфигурация
Создайте в корне проекта файл .env, в котором будут храниться следующие параметры:
- DATABASE_URL - Ссылка на базу данных PostgresSQL
- SECRET_KEY - ключ для генерации JWT токенов
